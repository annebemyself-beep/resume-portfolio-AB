# Ananya Balu – Portfolio site

Static HTML/CSS site for GitHub Pages. Upload the contents of this folder to the root of your repository
(so `index.html` sits at the top level), then enable Pages in Settings → Pages.

## Pages
- `index.html` – resume
- `projects.html` – project list
- `thrifti-lux.html` – Thrifti-Lux case study (stages, no years)
- `kundalini-yoga.html` – Kundalini Yoga: An Exploration
- `contact.html` – contact

## Files
- `style.css` shared theme · `project.css` project pages · `kundalini.css` Kundalini colours
- `bear.js` scroll bear (recreated – replace with your original if you have it)
- `images/` pictures and slide previews · `docs/` PDFs and the Kundalini PPTX
